使用说明

从安装到开始写第一篇文章，大约需要两分钟。

1. 安装

  1. 从下载页面获取 ZiJi-Setup-*.exe（版本号以后缀区分，选最新的）。
  2. 双击运行，按提示完成安装。
  3. 安装完成后从开始菜单或桌面图标启动。

Windows 10 以上即可，无需安装其他依赖。如果你的系统没有 WebView2 组件，安装包会自动处理。

2. 第一次使用：选择你的文章文件夹

启动后，应用会请你选择一个文件夹来存放文章。这个文件夹完全归你管：

  • 每篇文章以 .md 文件保存在里面，用记事本都能打开；
  • 想备份，直接复制整个文件夹；
  • 想换电脑，把文件夹拷过去，在新电脑的字己里重新选中它即可。

建议选一个你会定期备份的位置（比如网盘同步目录），这样连备份都省了。

3. 日常写作

  • 新建文章：Ctrl + N，或点界面上的新建按钮。
  • 写正文：支持 Markdown 语法（标题、粗体、列表等），Ctrl + S 保存。
  • 分类和标签：写在文章开头的属性区，用于之后的筛选。
  • 草稿保护：编辑过程中自动保存草稿，误关窗口不丢字。

4. 整理与回看

  • 搜索：Ctrl + F 聚焦搜索框，按标题、正文、标签全文检索。
  • 筛选：按分类、标签一键过滤，快速翻找同类文章。
  • 写作日历：首页的日历图记录每天的写作字数，回看自己的坚持。

5. 数据安全

  • 自动备份：每次编辑保存前，原文件会备份到文章文件夹下的 .selfrblog-backups/。
  • 回收站：删除的文章进入 .selfrblog-trash/，不会立即消失，可自行找回。
  • 不联网：字己不会把你的文字上传到任何服务器。

6. 常见问题

换电脑了，文章怎么办？
把文章文件夹整个复制到新电脑，在新装的字己里选择这个文件夹，所有文章原样出现。
可以用其他软件编辑这些文章吗？
可以。文章就是普通的 Markdown 文件，Typora、VS Code 等任何编辑器都能打开，互不干扰。
字己会收集我的数据吗？
不会。无账号、无联网上报，所有数据只存在于你的电脑里。
如何更新到新版本？
下载新版安装包直接安装覆盖即可，文章文件夹和配置不受影响。
