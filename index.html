字己

私人的文字档案馆

用文字记录自己，在回看中重新理解自己。
不发表、不社交、不上传——文章以 Markdown 保存在你自己的电脑里。

下载 Windows 版 使用说明

Windows 10 及以上 · 免费 · 数据存在你自己的文件夹里

本地优先

数据归你所有，不绑定账号，不锁定格式。

写给自己

默认场景是记录和回看，不是发布和传播。

安静克制

只提供必要的整理能力，不制造维护负担。

它做什么

✍️

Markdown 写作

标题、分类、标签、常用快捷键，专注写正文。

📂

开放格式

每篇文章是一个 .md 文件，随时可以换别的编辑器打开。

🔍

全文搜索

按标题、正文、标签检索，积累再多也能立刻找到。

🏷️

分类与标签

自动从文章中提取分类和标签，一键筛选回看。

📊

写作日历

GitHub 风格的记录图，看见自己持续写作的轨迹。

🛡️

备份与回收站

编辑自动备份，删除先进回收站，不轻易弄丢一个字。

你的文字存在哪里？

就在你选的那个文件夹里，一个字都不在别人的服务器上。

开放格式每篇文章是一个 Markdown 文件，记事本都能打开。
随时迁移整个文件夹复制走，换电脑、换软件都不受影响。
离线可用不依赖网络，断网照常写作和回看。
